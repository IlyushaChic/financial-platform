# 💳 Financial Platform — Frontend

> React SPA для управления финансами: баланс, переводы, история транзакций, уведомления в реальном времени.

---

## 🧩 Стек

- **React 18** + **TypeScript**  
- **Vite** — быстрая сборка  
- **Apollo Client** — GraphQL (включая подписки WebSocket)  
- **Redux Toolkit** — управление состоянием  
- **Tailwind CSS** — стилизация  
- **React Router DOM** — маршрутизация  
- **React Hot Toast** — уведомления  

---

## 🚀 Быстрый старт

### 1. Установи зависимости

```bash
npm install

2. Запусти dev-сервер
bash
npm run dev
Приложение будет доступно по адресу http://localhost:5173.

3. Сборка для production
bash
npm run build
📡 Взаимодействие с бэкендом
HTTP GraphQL — основной API (регистрация, логин, баланс, переводы).

WebSocket — подписка на новые транзакции (обновление баланса в реальном времени).

Apollo Client настроен на работу с API Gateway (http://localhost:8080/query).

🔧 Переменные окружения
Создай файл .env в корне frontend/:

env
VITE_GRAPHQL_URL=http://localhost:8080/query
VITE_WS_URL=ws://localhost:8080/query
Если не заданы, используются значения по умолчанию из apollo/client.ts.

📁 Структура проекта (основные папки)
text
src/
├── api/           # Apollo Client и WebSocket настройки
├── components/    # UI-компоненты (atoms, molecules, organisms)
├── pages/         # Страницы (Login, Register, Dashboard)
├── store/         # Redux slices (auth, balance, transactions)
├── hooks/         # Кастомные хуки
├── utils/         # Утилиты (форматтеры, валидация)
└── App.tsx        # Главный компонент с роутингом
🧪 Тесты
Запустить unit-тесты (если есть):

bash
npm run test
📌 Дополнительно
Tailwind — стили настраиваются через tailwind.config.js и index.css.

Линтинг — используется ESLint с конфигурацией для TypeScript и React.
